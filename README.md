# crumb

A mobile-first grocery planning prototype. See what you have at home, discover recipes, and turn your meal choices into a shopping list.

The demo starts with sample ingredients and saves changes in your browser. Receipt scanning is simulated.

## Run locally

Use Node.js 22.12+ and npm.

```sh
git clone https://github.com/antonmunsin/crumb.git
cd crumb
npm ci
npm run dev
```

Open the local URL printed in the terminal.

## Tests and build

```sh
npm test
npm run build
```
